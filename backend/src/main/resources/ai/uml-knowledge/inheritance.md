# SW1-UML-INHERITANCE

- Tema: herencia y generalización
- Fuente: OMG UML 2.5.1, formal/2017-12-05, https://www.omg.org/spec/UML/2.5.1/
- Versión: 1.0

## Reglas verificables

- Una relación `INHERITANCE` representa una generalización entre dos clases del modelo.
- La dirección y los IDs de ambos extremos deben corresponder a clases existentes.

## Elementos opcionales

- Una clase puede no declarar herencia.

## Ejemplos

- Válido: `Alumno` generaliza desde `Persona` si ambos IDs existen.

## Limitaciones

- No se deduce una jerarquía por similitud de nombres o atributos.
